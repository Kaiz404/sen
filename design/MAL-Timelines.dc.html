Haptic beat · reduced motion

One light impact per launch, on the landing: MAL1 1722, MAL2 1512, MAL3 1176, MAL4 2100 ms. Fire it with runOnJS(Haptics.impactAsync)(Light) from the landing segment's withTiming callback, not a setTimeout, so it stays in sync on a dropped frame. No haptic on the handoff or in the wait loop.

Sparkles, ticks, swoosh only appear on that beat: 3 four-point stars (lemon, lilac, paper) pop in with the spring over 150 ms and are gone by 460 ms. 3 paper ticks flick outward. The swoosh is a paper stroke at 30% that draws, then erases.

Reduced motion (useReducedMotion): show the rest frame (the board's static pose), hold 400 ms, then a 200 ms opacity crossfade to Lock. No travel, no accents, no haptic.

Build cost

react-native-svg: the Sen rig only (rim, face, eyes, mouth, paws, cheeks). Move, scale, lean and squash Sen on wrapping Animated.Views on the UI thread. Use useAnimatedProps on a G only for paws, eyes and the face look. Coins, the well, the slot and the floor are plain Views.

Font metrics: MAL1, MAL3 and MAL4 need only the period's position (one onLayout). MAL2 needs every letter's centre and top. Cheapest for all four: outline "Sen" to SVG paths once, so the positions become constants that match the splash PNG pixel for pixel.

expo-splash-screen: the static image must equal frame 0, on #17181A at the same scale and position. Call hideAsync in the loader's first onLayout. MAL2's frame 0 has no period, so it reads as unfinished on a slow device. On Android 12 and up the system splash shows only a centred icon, so use a lemon coin and crossfade it into frame 0.
