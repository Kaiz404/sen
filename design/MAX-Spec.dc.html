Sen motion spec

Body transforms run on Animated.View wrappers, outside in: mv (translate) › rl (rotate about the coin centre) › sq (rotate, skewX, scale about the contact point, the bottom of the rim) › sp (scaleX about the centre). Face parts are react-native-svg G elements driven by useAnimatedProps: lk (the face group, eyes + mouth, translated across the disc and clipped by a ClipPath of the face circle r 222 so it can tuck behind the rim), eye-l/eye-r (open ellipse and closed arc, opacity crossfade, blink scaleY), mouth (opacity crossfade of 6 pre-drawn paths), paw-l/paw-r (wave, perch, hold props, celebrate; never on the face), cheeks, heads/tails, edge pill, props. Masked is eyes closed with lk at (0, 34); revealed is lk up and eyes open. Accents (3 stars, 3 ticks, 1 swoosh) are a sibling layer that follows mv only, never the spin. Rig units: face radius 222, rim 262; 1 unit = size / 600 pt.

const EASE = {
  out:  Easing.bezier(0.2, 0.8, 0.2, 1),   // arrivals, eye moves
  inQ:  Easing.in(Easing.quad),            // falls, exits
  outQ: Easing.out(Easing.quad),           // rises
  sine: Easing.inOut(Easing.sin),          // holds, returns
  inS:  Easing.in(Easing.sin),             // spin toward edge-on
  outS: Easing.out(Easing.sin),            // spin away from edge-on
};
const SPRING = {                            // all damped: one overshoot, then settle

};

Reduced motionRead useReducedMotion() and pass reduceMotion: ReduceMotion.System in every withTiming and withSpring. Pose changes become 150 ms opacity crossfades. Keep blinks; drop hops, spins, flips, rolls, wobbles, stretch and accents. Haptics still fire because they carry meaning. The CSS on these boards uses @media (prefers-reduced-motion: reduce) to show each end pose.
Never during scrollThe scheduler pauses on onScrollBeginDrag and onMomentumScrollBegin, and resumes 1.5 s after momentum ends. Ambient beats in flight are cancelled (cancelAnimation) and eased to rest in 120 ms. The only exception is the pull-to-refresh stretch, which is direct manipulation, not playback.
One attention motion at a timeA single MotionDirector owns every Sen. Priorities: P3 error and lockout; P2 unlock, reveal and re-mask; P1 copy, refresh, empty search and theme; P0 idle, lock peeks and ring glances. A higher priority cancels a lower one. Equal priorities queue at most one. P0 is dropped, never queued. Only one Sen on screen animates at a time.
RestraintIdle is almost still: eyes only, no body motion. Big motion (roll, flip, accents) is reserved for launch, unlock and reveal. Copy gets one small hop. No repeated wobble except the Euler settle.
Off screenNothing plays when the screen is unfocused (useIsFocused) or AppState is not active. When the app goes to the background, set the re-mask pose instantly.
Haptic pairingOne haptic per moment. Fire it through runOnJS from the step named in the table, not at gesture start. iOS uses expo-haptics: notificationAsync, impactAsync and selectionAsync. Android uses performAndroidHapticsAsync(AndroidHaptics.X). If the user has turned off system haptics, the OS keeps them silent.
PerformanceBody transforms use Animated.View wrappers so they run as native transforms on the UI thread. SVG parts use useAnimatedProps, with at most 12 animated props. The mouth crossfades between pre-drawn paths instead of morphing d. Accents unmount after they play.
Face, not pawsPaws share the rim colour, so they never touch or cover the face. Hiding is told by the eyes and the face group: closed arcs and a small tuck when masked, one eye opening a crack when peeking, the face sliding up with eyes popping open on reveal. Paws wave, perch, hold the one prop and celebrate.
